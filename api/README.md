# API

This starter keeps the UI data-driven and local. When you add server APIs, recommended routes are:

- `/api/exams`
- `/api/subjects`
- `/api/questions`
- `/api/mock-tests`
- `/api/results`
- `/api/bookmarks`
- `/api/leaderboard`

For Next.js App Router, implement these under `app/api/.../route.ts`.
