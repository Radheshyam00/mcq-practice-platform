# MCQ Practice Platform

A complete Next.js + TypeScript + Tailwind CSS starter for practicing multiple-choice questions across competitive and professional exams.

## Features

- Exam and subject browsing
- Practice mode
- Mock tests
- Daily quiz
- Question details
- Bookmarking and history using browser localStorage
- Quiz timer, navigation, scoring and explanations
- Leaderboard demo
- Search
- Responsive dark/light UI
- Admin UI starter
- Data-driven exam/question architecture

## Run

```bash
npm install
npm run dev
```

Open http://localhost:3000.

The application currently uses local TypeScript data so it works immediately. `lib/db.ts` and `lib/auth.ts` are intentionally provider-neutral extension points for adding MongoDB/PostgreSQL and Auth.js later.
